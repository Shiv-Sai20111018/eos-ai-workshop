# ▶️ How to Run ShivBot AI Assistant on Your Laptop

## 📌 Step 1 — Install Python

First, install Python on your laptop.

Download Python from:

[Python Official Website](https://www.python.org/downloads/?utm_source=chatgpt.com)

While installing:
✅ IMPORTANT:
check this option:

```text
Add Python to PATH
```

Then click:
```text
Install Now
```

---

# 📌 Step 2 — Download the Project

Open the GitHub repository:

[EOS AI Workshop Repo](https://github.com/Shiv-Sai20111018/eos-ai-workshop?utm_source=chatgpt.com)

---

## 📌 Download ZIP

Click:

```text
Code
```

↓

```text
Download ZIP
```

---

# 📌 Step 3 — Extract the ZIP File

After downloading:

1. Right click ZIP file
2. Click:
```text
Extract All
```

Now the project folder will appear.

---

# 📌 Step 4 — Open the Project Folder

Open:

```text
eos-ai-workshop
```

Then open:

```text
chatbot-project
```

You should see:

```text
README.md
chatbot.py
```

---

# 📌 Step 5 — Open Terminal

Inside the folder:

### Windows

Right click empty space inside folder.

Click:

```text
Open in Terminal
```

OR

```text
Open PowerShell window here
```

---

# 📌 Step 6 — Run the Chatbot

Type:

```bash
python chatbot.py
```

Then press ENTER.

---

# 🤖 Chatbot Starts Running

You should now see:

```text
==================================================
🤖 ShivBot AI Assistant
Type 'bye' to exit
==================================================
```

---

# 🚨 Common Errors and Fixes

# ❌ Error:

```text
python is not recognized
```

✅ Fix:
Python was not added to PATH.

Reinstall Python and enable:

```text
Add Python to PATH
```

---

# ❌ Error:

```text
No module found
```

✅ Fix:
Make sure:
- Python installed correctly
- chatbot.py exists inside folder

---
