# 📚 What I Learned

## 1️⃣ Variables and Data Types

* A variable is like a box 📦 where we can keep information.

* I practiced using *int, float, str, and bool*.

```python id="0shs58"
age = 15        # integer
pi = 3.14159    # float
name = "Shiv Sai Subramonyam"   # string
is_student = True   # boolean
```

* I learned that the `=` sign does not mean equal like in maths ➗. It means storing a value.

* Variables store information. Data types tell what type of information is inside. Integers store whole numbers 🔢, floats store decimal numbers 📊, strings store text ✍️, and booleans store True or False ✅❌.

---

## 2️⃣ Collections

* *Lists:* Ordered items stored together.

```python id="cb2ysx"
subjects = ["Maths", "Physics", "CS"]
```

* *Dictionaries:* Information stored with keys and values.

```python id="9q1r9t"
student = {"name": "Priya", "grade": 11, "score": 92}
```

* I learned when to use lists and when to use dictionaries.

* Collections help us store many pieces of data together 📂. Lists store items in order, while dictionaries store information in a more organized way.

---

## 3️⃣ Control Flow

* Using *if, elif, and else*, I made a grade calculator 📊.

```python id="6p37od"
score = 85

if score >= 90:
    grade = "A"

elif score >= 75:
    grade = "B"

else:
    grade = "C"
```

* This helped me understand how computers make choices step by step 🤖.

* Control flow helps the program decide what to do depending on conditions.

---

## 4️⃣ Loops

* For loops helped me repeat work 🔁.

```python id="qrrb9f"
for subject in subjects:
    print(f"Studying {subject}")
```

* I also used `range()` to repeat something many times.

* Loops help us repeat the same work without writing the code again and again ⏳.

---

## 5️⃣ Functions

* Functions are like reusable recipes 🍳.

```python id="lt8w2v"
def calculate_percentage(marks):
    total = sum(marks)
    return total / (len(marks) * 100) * 100
```

* Functions are blocks of code used for doing a task ⚙️. They help make programs shorter and cleaner.

---

## 6️⃣ f-Strings and List Comprehensions

* *f-strings made printing easier:*

```python id="m6xj9m"
print(f"My name is {name} and I am {age}")
```

* *List comprehensions helped me create lists in one line:*

```python id="d11ehj"
squares = [x**2 for x in range(10)]
```

* f-Strings help us add variables inside text ✍️. List comprehensions help us make lists quickly ⚡.
